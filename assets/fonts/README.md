# Report fonts

The generated PDF embeds the four Browallia New faces below. Word reports
declare `Browallia New` for ASCII, Latin, Thai, and complex-script runs.

- `BrowalliaNew-Regular.ttf`
- `BrowalliaNew-Bold.ttf`
- `BrowalliaNew-Italic.ttf`
- `BrowalliaNew-BoldItalic.ttf`

These files were extracted from the Browallia font collection supplied for
this deployment. They are deployment assets and are not covered by this
repository's MIT license. Keep or distribute them only under the font license
available to the repository owner.
